\# Получение данных устройства через mitmproxy



Эта инструкция для \*\*продвинутых пользователей\*\*, которые

знают, как работать с прокси.



\## Что понадобится



\- Компьютер в той же Wi-Fi-сети, что и смартфон

\- mitmproxy на компьютере: https://mitmproxy.org/downloads/

\- Установленный Happ на смартфоне



\## Шаги



\### 1. Запустить mitmproxy



```sh

mitmproxy -p 8080

```



\### 2. Настроить прокси на телефоне



Настройки Wi-Fi → ваша сеть → Дополнительно → Прокси:

\- Хост: IP компьютера

\- Порт: 8080



\### 3. Установить сертификат



Откройте http://mitm.it на телефоне, скачайте сертификат

для Android и установите.



\### 4. Захватить трафик



1\. Откройте Happ

2\. Обновите подписку

3\. В mitmproxy найдите запрос к серверу подписки

&#x20;  (URL оканчивается на sub.php)



\### 5. Посмотреть заголовки



| Заголовок | Что это |

|---|---|

| `X-HWID` | HWID |

| `User-Agent` | `Happ/4.3.0/Android/17877...` — число после `Android/` = UA Device ID |

| `X-Device-Model` | модель устройства |



\### 6. Скопировать значения



Вернитесь в инсталлер и заполните:

\- HWID: значение `X-HWID`

\- UA Device ID: число из User-Agent

\- Модель: значение `X-Device-Model`



\## Отключение прокси



После захвата: настройки Wi-Fi → ваша сеть → Прокси → Отключить.
