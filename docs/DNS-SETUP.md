\# Настройка DNS в Keenetic



В условиях белого списка оператора обычные DNS-серверы

(1.1.1.1, 8.8.8.8) блокируются. Yandex DNS обычно

остаётся доступен.



\## Через веб-интерфейс



1\. Откройте http://192.168.1.1 (или my.keenetic.net)

2\. Перейдите: \*\*Интернет → Фильтры → Настройка DNS\*\*

3\. Добавьте как plain-DNS:

&#x20;  - `77.88.8.8`

&#x20;  - `77.88.8.1`

4\. Если есть DoH-серверы — оставьте их как резерв.

5\. Сохраните.



\## Проверка из SSH



```sh

nslookup ya.ru 77.88.8.8   # должен ответить

nslookup ya.ru 1.1.1.1     # при whitelist может не ответить

```



Если Yandex DNS тоже блокируется — переходите на DoH/DoT

через VPN.
